# 기초 커리큘럼 초안

4/4 두 마디와 시작 60 BPM으로 손발 조합을 단계적으로 늘린다.

| 순서 | 연습 | 목표 |
| --- | --- | --- |
| 1 | 닫힌 하이햇 4분음표 | 네 박을 고르게 유지 |
| 2 | 닫힌 하이햇 8분음표 | 박과 앤드를 균등하게 분할 |
| 3 | 닫힌 하이햇 8분음표와 스네어 2·4박 | 같은 박에 두 손을 함께 사용 |
| 4 | 위 패턴에 킥 1·3박 추가 | 손발을 조합한다. 현재 기본 8비트 레슨을 재사용한다. |

단계마다 **예시 → 따라 하기 → 독립 연주 → 오답 박 반복**을 제공한다. 악기별 성공률과 동시 타격 조합 완성률을 관찰한다. 목표 속도와 성취 기준은 실기기 파일럿에서 조정할 초안이다.

기본 Wait는 순서와 조합 완료만 기록한다. 고정 100ms 기준은 두지 않으며, 동시성 자체가 학습 목표인 별도 연습에서 시간 기준을 검토한다. Wait 기록은 실시간 박자 점수와 자동 BPM 추천에서 제외한다.

이후 손발 독립, 루디먼트, 필인·강약, 셔플·싱코페이션, 장르, 사용자 악보 실전의 선행 관계를 검증한다. 손 사용을 안내할 수 있다. 실제 사용한 손과 자세는 MIDI로 검증할 수 없다.
