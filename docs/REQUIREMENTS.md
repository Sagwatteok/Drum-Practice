# 요구사항

## 목표

Yamaha DTX452K(DTX402)와 Galaxy S23 Ultra를 USB-C ↔ USB-B 데이터 케이블로 연결해 실제 타격을 기반으로 연습한다. 모듈 자체 음원과 메트로놈·반주를 PHONES/OUTPUT에서 함께 듣는 구성을 우선 검증한다. Kotlin·Jetpack Compose 단일 Android 앱을 유지한다. 핵심 연습, 콘텐츠, 채점과 기록은 오프라인에서 사용하며 계정, 구독, 필수 서버나 런타임 AI API를 요구하지 않는다.

## 현재 구현

- Android USB 호스트와 MIDI 지원 표시, USB 장치 및 출력 포트 탐색, 선택·해제·재연결
- Note On/Off, Velocity, 채널, Control Change, 원본 바이트와 단조 증가 시각 표시
- 출력 장치 목록, 선택 가능한 USB 오디오 경로, 120 BPM 테스트음과 AudioTrack 실제 라우팅 표시, 재생 중 실제 USB MIDI 카운터
- 드럼별 매핑, MIDI Learn, 직접 편집과 로컬 저장. 초기 노트는 General MIDI 예시로 사용한다.
- 자유 연주의 USB·Mock별 횟수, 드럼별 타격 강도와 동시 타격 표시, 최근 진단 로그와 초기화
- 화면 터치 및 BPM 기반 Mock 입력, 정박·이른 타격·늦은 타격·누락·다른 드럼·동시 타격·임의 편차·연결 해제 시뮬레이션
- 세로·가로, 시스템 다크 모드, 연주 중 화면 켜짐 유지
- PCM 메트로놈, 오디오 프레임 시간축, USB·Mock 독립 채점. Perfect/Great/Good/Bad 초기 기준은 ±25/50/80/120ms이며 누락, 추가, 다른 드럼과 동시 타격을 처리한다.
- 기본 8비트 두 마디, 60 BPM, 4/4 한 마디 카운트인, 구간 반복과 템포 변경, 가로·세로 악보.
- 에뮬레이터 검증을 수행했다. 목표 기기의 단일 케이블 MIDI·오디오 동시 동작, 헤드폰 청취, Note·CC 매핑, 지연 및 재연결은 [실기기 확인](HARDWARE_TEST.md)이 남아 있다.

## 후속 기능

- Phase 2 입력 신뢰성을 우선한다. 제한된 큐에서 허용된 패킷 순서와 이벤트 시각을 보존한다. 포화 때 버려진 패킷과 파싱된 타격을 세고 해당 시도가 신뢰도 저하 상태임을 표시한다. 최근 100개 표시 제한과 누락 계수는 별개다.
- 입력·오디오·화면 오프셋을 별도로 보정한다. 장시간 drift와 jitter를 관측하며 앱 내부 시각과 물리 타격부터 헤드폰 출력까지의 지연을 구분한다.
- 렌더링과 채점에 검증된 동일 [Tick 악보](SCORE_FORMAT.md)를 이용한다. 자체 [기초 콘텐츠](LEARNING_CURRICULUM.md)와 시드 기반 패턴을 오프라인에서 재현한다. 외부 자료는 출처와 라이선스를 명시한다.
- MIDI 가져오기를 먼저 검증하고 MusicXML을 이어서 지원한다. 원본 파일은 보존하고 미지원 구조와 변환 경고를 표시한다.
- 검증된 실시간 연주 기록으로 악기·마디별 약점, 타이밍과 Velocity 추세, 규칙 기반 추천 및 BPM 조정을 제공한다. 학습 기록은 로컬에 보관한다.
- MIDI만으로 손 사용, 손목 움직임이나 자세를 검증할 수 없다. Velocity는 모듈 설정의 영향을 받으며 하이햇 상태와 림 범위는 실기기 Note·CC 확인 후 확장한다.
