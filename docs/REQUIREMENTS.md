# 요구사항

## 목표

Yamaha DTX452K(DTX402)와 Galaxy S23 Ultra를 USB-C ↔ USB-B 데이터 케이블로 연결해 실제 타격을 기반으로 연습한다. 헤드폰은 모듈의 PHONES/OUTPUT에 꽂고 모듈의 드럼 소리와 앱의 반주 또는 메트로놈을 듣는다. 초기 버전은 오디오 인터페이스, 블루투스, 외부 서버 및 AI API 없이 동작한다.

## 초기 구현

- Android USB 호스트와 MIDI 지원 표시, USB 장치 및 출력 포트 탐색, 선택·해제·재연결
- Note On/Off, Velocity, 채널, Control Change, 원본 바이트와 단조 증가 시각 표시
- 출력 장치 목록, 선택 가능한 USB 오디오 경로, 120 BPM 테스트음과 AudioTrack 실제 라우팅 표시, 재생 중 실제 USB MIDI 카운터
- 드럼별 매핑, MIDI Learn, 직접 편집과 로컬 저장. 초기 노트는 General MIDI 예시로 사용한다.
- 자유 연주의 USB·Mock별 횟수, 드럼별 타격 강도와 동시 타격 표시, 최근 진단 로그와 초기화
- 화면 터치 및 BPM 기반 Mock 입력, 정박·이른 타격·늦은 타격·누락·다른 드럼·동시 타격·임의 편차·연결 해제 시뮬레이션
- 세로·가로, 시스템 다크 모드, 연주 중 화면 켜짐 유지

## 후속 기능

- 공통 오디오 타임라인, 별도 MIDI/오디오/표시 오프셋, 자동·수동 보정, jitter 및 타격 편차
- Perfect/Great/Good/Bad/Miss 초기 기준 ±25/50/80/120 ms, Early/Late/Wrong Drum/Extra Hit, 동시 타격 독립 매칭
- 메트로놈 박자표·세분음·강세·카운트인·속도 증가, 악보·리듬 게임·구간 반복·난이도·5단계 레슨
- 음악/MIDI/악보 파일 가져오기, 재생 속도·동기화·반복, 연주 결과 및 드럼별 Velocity 분포
- Room 기록, 연습 목표·XP·연속 학습일·업적·진행률·통계·규칙 기반 추천
- AI 코칭, 음원 분리, 자동 채보, 자동 커리큘럼은 MVP 이후 평가한다.
