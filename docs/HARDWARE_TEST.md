# 하드웨어 테스트

대상은 Galaxy S23 Ultra, Yamaha DTX452K의 DTX402 모듈, USB-C ↔ USB-B 데이터 케이블과 모듈에 연결한 유선 헤드폰입니다. Yamaha 설명서는 USB TO HOST의 디지털 MIDI 및 오디오 전송을 명시합니다. 아래 절차는 해당 Android 기기에서의 동작을 확인하기 위한 것입니다. [Yamaha 공식 사용설명서, 15·58쪽](https://data.yamaha.com/files/download/other_assets/1/1181111/VHY8310_DTX402K_432K_452K_owners_manual_En_C0.pdf)

## 실기기 절차

1. 모듈을 켜고 헤드폰을 PHONES/OUTPUT에 꽂습니다. 드럼 타격 소리를 확인하고 볼륨을 낮춥니다. 앱을 설치한 뒤 USB 데이터 케이블로 연결합니다.
2. **연결 진단**에서 USB VID/PID, USB 호스트 지원, Android MIDI 지원을 기록합니다. MIDI 포트가 보이면 선택하고 화면 상단 연결명을 기록합니다.
3. 킥, 스네어 중앙과 림, 닫힌/열린 하이햇과 페달, 각 탐·크래시·라이드를 약/중/강으로 3번씩 칩니다. Note/Velocity/채널과 CC 번호·값을 기록합니다. 하이햇은 타격 없이 페달만 움직이는 경우도 검사합니다.
4. 연습 세션을 초기화합니다. USB 출력이 보이면 해당 출력을 선택하고 **12초 테스트음 재생**을 누릅니다. **실제 출력**이 모듈 USB를 가리키는지와 테스트음이 모듈 헤드폰에서 들리는지 각각 확인합니다.
5. 테스트음이 재생되는 동안 실제 패드를 여러 번 치고 드럼 자체 음과 테스트음을 동시에 듣습니다. 재생 중 Note On 증가, 실제 경로, 동시 카운터와 로그를 기록합니다. 다른 USB 오디오 장치는 제외합니다.
6. 재생 중 케이블을 분리하고 실제 오디오 경로 변경 및 MIDI 연결 해제를 확인합니다. 같은 케이블로 다시 연결해 포트 자동 재연결 후 타격을 확인합니다. 앱의 **연결 해제**를 누른 뒤 자동 연결이 취소되는지도 검사합니다.
7. **매핑**에서 미지정 패드를 Learn으로 등록하고 앱을 다시 실행해 유지되는지 확인합니다. 림샷이나 페달의 메시지가 예상과 다르면 원본을 기록합니다.
8. MIDI 시각→수신 및 수신→처리의 평균·표준편차·표본 수를 기록합니다. 이 수치는 앱에서 관측한 시간 간격입니다. 실제 패드 타격부터 헤드폰까지의 지연을 구하려면 외부 계측이 필요합니다.

## 문제 해결

- USB 장치가 없으면 데이터 지원 케이블, 모듈 전원, USB-C 호스트 연결을 확인하고 **다시 검색**을 누릅니다.
- MIDI는 동작하고 USB 오디오가 잡히지 않으면 Android의 개발자 옵션에서 USB 오디오 라우팅 비활성화 설정을 확인합니다. USB 출력 목록과 실제 출력은 각각 기록합니다.
- AUX IN 대체 경로는 USB MIDI 연결을 유지하면서 별도로 확보한 아날로그 음원을 3.5 mm 스테레오 케이블로 AUX IN에 넣습니다. S23 Ultra의 USB-C 한 포트를 이미 MIDI에 사용하고 있다면 스마트폰 음성을 AUX IN으로 보내려면 MIDI 연결과 동시에 아날로그 출력을 제공하는 호환 액세서리 또는 별도 재생기가 필요합니다. 별도 재생기는 앱의 테스트음·반주와 독립적으로 동작합니다.
